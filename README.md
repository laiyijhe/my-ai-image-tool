## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Docker Compose (root `docker-compose.yml`)

- Frontend (HereForGrant): [http://localhost:3005](http://localhost:3005) (host port **3005** → container **3000**).
- Backend API: [http://localhost:8001](http://localhost:8001) (host **8001** → container **8000**). For the Next.js **server** (e.g. `/api/search` proxy), set `BACKEND_INTERNAL_URL=http://backend:8000` in Compose; browsers still use `NEXT_PUBLIC_API=http://localhost:8001` when calling the API from the client.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
